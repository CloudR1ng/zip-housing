# .ZIP — 나의 생활에 맞는 집

2026 GovTech 주거 생활권 탐색 MVP. 전국 17개 시도의 합성 생활권 68건을 예산·보증금·이동시간·면적으로 필터링하고, HII 설명용 산식으로 비교합니다.

## 실행

Node.js 22 이상에서 `npm ci`, `npm run dev`. 배포 빌드는 `npm run build`, 검증은 `npm test`입니다. GitHub Pages는 main에 push하면 Actions로 배포됩니다.

## AI 연결

사이트 오른쪽 위 **AI 연결**에서 본인의 Gemini API 키를 입력하고, 모델 목록을 불러온 후 사용할 모델을 선택합니다. 무료 한도는 Google AI Studio에서 프로젝트와 모델별로 확인해야 합니다. 기본 모델은 gemini-2.5-flash이며 사용 불가능하면 목록에서 다른 텍스트 모델을 선택합니다.

키는 페이지 메모리에만 유지되고 새로고침 시 사라집니다. 키를 소스·저장소·URL에 넣지 마세요. 대화와 탐색 조건은 Google Gemini API로 직접 전송됩니다. GitHub Pages에는 서버 비밀키를 보관할 수 없으므로 이 MVP는 사용자가 자신의 키를 입력하는 방식입니다. 서비스 공용 키를 쓰려면 별도의 서버 중계가 필요합니다.

AI는 `search_candidates`, `compare_candidates`, `explain_score` 함수를 선택하여 실행합니다. 앱은 허용된 도구만 실행하고 결과를 AI에 반환합니다. 매 요청은 최대 6회 모델 호출, 90초 시간 제한을 적용합니다. API 오류 시 데모 응답으로 위장하지 않고 오류를 표시합니다. 키가 없을 때의 데모는 명시적으로 표시된 제한된 문장 처리 방식입니다.

## 시연 범위와 한계

- 모든 가격, 면적, 시설 점수, 노후도, 거주 불확실성, 이동시간은 **합성 시연 데이터**입니다. 실제 매물 또는 공공데이터 조회가 아닙니다.
- 좌표는 시연용 근사 위치이며 정확한 주소가 아닙니다. 각 시도에서 4개 생활권만 예시로 제공합니다.
- 이동시간은 시도별 고정 목적지에 대한 합성값입니다. 목적지 변경·실제 경로 계산은 지원하지 않습니다.
- 월 예산은 월세와 관리비의 합계입니다. 필수조건 미충족 후보를 자동으로 포함하지 않습니다.
- HII는 공인 지수가 아닌 MVP 설명용 가중 합계입니다. 적합도는 100-HII입니다. 구체적인 계산과 가중치는 `src/data.js`, 화면의 추천 기준에서 확인할 수 있습니다.
- 저장한 생활권 ID만 localStorage에 남습니다. 비교 결과는 텍스트 파일로 내려받을 수 있습니다.
- 지도는 OpenStreetMap 타일, 아이콘은 Lucide를 사용합니다. 지도 연결 실패 시 목록 탐색은 계속 가능합니다.
- 실제 매물, 정책 자격, 계약·투자 판단에 사용하면 안 됩니다.

## 검증

전국 데이터 일관성, 필수조건 및 빈 결과, 점수 재현성, 입력 정규화, AI 도구 호출 왕복을 자동 검증합니다. AI 테스트는 모의 API이며 실제 계정의 한도·키 유효성을 보증하지 않습니다.
